## 설계 문서와 견주어 확인

- [x] 벡터와 팽이 움직임이 같은 상태(q·L)를 쓴다. (화면 보간은 표시용)
- [x] 보존 검사 5개 통과: g=0이면 L 일정 / 공 모양이면 ω∥L / 수직이면 토크 0 /
      Δt 절반 1초 수렴 + q 크기 오차 1e-10 이하 / 10초 드리프트 0.5% 이내 (실측 0.000%).
- [x] 근사 한계 표시: 근사는 ‘비교용’ 글자와 함께, 20% 이상 어긋나면 ‘근사가 어긋남’ 안내.
- [x] 실패 숨기지 않음: 수치 오류면 오류 상자 + 마지막 상태 + 초기값 복원 버튼.
- [x] 오른손 법칙 방향: 초기 토크 (0, 0.254, 0) N·m을 손으로 계산한 값과 맞춰봄.
- [x] gi-pulse는 한 버튼에만. 업데이트 내역 버튼은 항상 같은 자리.
- [x] VoiceOver·TTS·자동 재생 오디오 없음 (설계 제외 항목).
- [x] UI 모듈 전부 500줄 이하 (main 459줄 포함 10개). 동작은 분리 전과 같음을
      한 단계·비교 저장으로 확인했다.
- [x] 손 점검 해소 (`docs/ACCESSIBILITY-CHECKS.md`): 고대비 대응 코드 + 확인,
      200% 확대 넘침 0, 읽기 순서(H1→H2→H3) 확인, 과제 문장 쉽게 고침.
- [x] 3D 보기(M4): 같은 계산 상태를 그림. 정면·위·옆이 카메라 위치, 자동 회전 없음.
      WebGL 실패 시 2D로 복귀 + 안내. 헤드리스 경고(ReadPixels stall)는 측정 환경 특유.
- [x] P1 별도 모델: 감쇠 끄면 P0와 결과 동일(검사). 감쇠 켜면 에너지 감소(검사).
      접촉 감지 켜면 닿을 때 `groundContact`로 끝남(검사 + 실제 조건 재현:
      35°·20 rad/s·R=0.15·h=0.02 → t=0.08 s 종료). 닿은 뒤는 계산 안 함을 화면에 밝힘.
- [x] 기록에 엔진 v0.2.0·시나리오 버전 포함. 실행 없이 저장 차단.

## 배포할 때 할 일 (이번에는 안 함)

1. `npm run build` → `dist/` 올리기 (`base`가 `"./"`라 하위 경로도 된다).
2. 공개 URL에서 자산 경로·실행·비교·기록·업데이트 내역 직접 확인.
3. 보고서에 배포 주소와 확인할 주소를 눌러서 가는 링크로 적기.
4. HVC 등록과 공개 갤러리 동기화는 별도 범위다.
