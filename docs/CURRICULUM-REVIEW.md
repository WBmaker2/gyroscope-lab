# 교과 검토 (물리 관점)

검토일: 2026-09-23. 검토자: AI (물리 전공 수준의 문헌·수식 대조).
**이 문서는 전문 검증을 대신하지 않는다.** 실제 수업 전 물리 교사의 확인이 필요하다.

## 1. 학습 목표와 화면의 연결

| 설계 목표 | 화면 구현 | 판정 |
|---|---|---|
| 중력 토크와 각운동량 방향 변화 연결 | L·τ·mg 벡터를 같은 상태에서 그림 | 맞다 |
| 빠른 회전 세차 근사와 일반 운동 구분 | 근사는 ‘비교용’, 수치는 별도 표시 | 맞다 |
| 느린 회전에서는 근사가 어긋남 | 차이 20% 넘으면 ‘근사가 어긋남’ 안내 | 맞다 |
| ‘중력이 작용하지 않는다’ 방지 | mg 벡터 항상 표시, 토크가 L을 바꿈을 보임 | 맞다 |
| ‘회전하면 항상 안 넘어진다’ 방지 | 60° 넘으면 종료, 감쇠 켜면 에너지 감소 | 맞다 |

## 2. 오른손 법칙 방향 확인

기본 조건(기울기 15°, 100 rad/s)의 초기 토크는 (0, +0.254, 0) N·m이다.
r이 +x 쪽으로 기울고 힘이 −z(중력)이므로 r×F는 +y다 (x̂×(−ẑ)=+ŷ).
세차는 +y 쪽 토크가 L(+z 쪽)을 쓰러뜨리는 방향, 즉 방위각이 도는 방향으로 나타난다.
수치 측정 세차 1.005 rad/s와 근사 0.981 rad/s의 부호·자릿수가 일치한다.

## 3. 단순화가 화면에 밝혀져 있는가

- 고정 지지점, 마찰·미끄럼·공기 저항 제외(P0): 조건 카드와 README에 있음.
- 지면 접촉은 ‘닿는 순간 끝내기’만 하고 닿은 뒤는 계산 안 함: P1 안내에 있음.
- 바퀴 반지름·지지점 높이·감쇠 계수는 가정값·고정값: 입력란과 안내에 ‘가정’, ‘고정’으로 밝힘.
- 수치 적분 오차: 드리프트를 %로 항상 표시, 목표 0.5% 병기.
- 화면 보간은 표시용: 푸터에 명시. 3D도 같은 계산 상태를 그림.
- ‘측정 Ω’은 실제 측정이 아니라 수치 적분 결과의 방위각 평균:
  ‘(수치)’ ‘(후반 50% 방위각 평균)’ 병기로 구분했다.

## 4. 화면 문구 검수 (오개념 유발 표현 찾기)

- 예측 선택지 ‘회전이 빨라서 거의 그대로 버틴다’는 오개념처럼 보이지만,
  예측→검증 구조의 선택지이며 채점하지 않으므로 문제없다.
- ‘너테이션’에는 ‘(떨림)’ 풀이를 붙였다.
- ‘빠른 회전 근사 범위 안의 실행입니다’는 측정값이 있을 때만 나온다.
  실행이 짧으면 ‘견줄 측정이 없습니다’로 바뀐다.
- RPM은 rad/s 옆에 보조로만 나온다 (변환값 취급).
- 전이 과제(무게중심 절반 → 근사에서 무엇이 바뀌는지)는 근사식
  Ω≈mgl/(Iω)에 l이 비례하므로 답이 하나로 모인다. 좋은 전이 과제다.

## 5. 학년 적합

- 중학교: 힘·운동·에너지 수준에서 벡터와 움직임으로 이해한다. 수식 없이 된다.
- 고등학교: 각운동량·토크·근사식까지 연결한다. ‘학년: 중학교~고등학교’ 표기가 맞다.
- 평가는 예측이 아니라 근거 기록으로 한다. 너테이션을 실패로 채점하지 않는다는
  설계가 화면 문구(‘떨려도 실패가 아닙니다’)와 일치한다.

## 6. 판정과 남은 조건

- **수업 사용 가능.** 단, 실제 수업 전 물리 교사의 눈으로 4번 문구를 한 번 더 보고,
  학생 1~2명 파일럿에서 예측 문장이 막히는지 확인할 것을 권한다.
