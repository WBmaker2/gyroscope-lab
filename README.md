# 넘어지지 않는 팽이 연구소 (`gyroscope-lab`)

‘회전하는 바퀴에 힘을 가하면 왜 예상과 다른 방향으로 움직일까?’
기울어진 회전 바퀴의 세차를 예측·실행·비교·기록하는 중·고등 물리 실험이다. (25분 활동)

- 공개 주소: https://wbmaker2.github.io/gyroscope-lab/
- 설계: `10-gyroscope-lab.md`, 공통 원칙: `00-shared-design-principles.md`
- 상태: P0 + 3D 보기(M4) + P1 별도 모델 완성, 배포 전 점검 마침 (`docs/PRE-DEPLOY-CHECK.md`)
- `main`에 올리면 자동으로 검사·빌드·게시된다 (`.github/workflows/deploy.yml`).

## 바로 시작하기

필요한 것: Node.js 18 이상.

```sh
npm install
npm run dev      # 개발 서버 http://127.0.0.1:5173/
npm test         # 물리 불변 검사 5개
npm run build    # 타입 검사 + 빌드 → dist/
npm run preview  # 빌드 결과 확인 http://127.0.0.1:4173/
```

## 폴더 구조

```text

  integrator.ts  RK4 고정 스텝 (Δt = 1/2000초, P1 감쇠 주입점)
```

## 물리 한 줄 요약

- 고정 지지점의 축대칭 강체. 질량 1kg, 무게중심 0.1m, I⊥=0.02, I축=0.01.
- 상태는 회전 쿼터니언 q와 세계 각운동량 L. 토크 τ=r×(0,0,−mg).
- 빠른 회전 근사 Ω≈mgl/(I축·ω)는 비교용이다. 모든 조건의 답이 아니다.
- 100 rad/s 예: 근사 0.981 rad/s, 수치 측정 약 1.005 rad/s.

## 학습 흐름 (예측 → 조건 → 실행 → 근거 → 재검증 → 전이)

1. 다음 움직임을 먼저 고른다 (3분).
2. 벡터를 켜고 한 단계씩 진행한다 (5분).
3. 회전 속도만 2배로 바꿔 비교한다 (7분).
4. 느린 회전에서 근사가 어긋나는 경우를 본다 (5분).
5. 이유를 한두 문장으로 적는다 (5분).
6. 전이: 무게중심 거리를 절반으로 줄이면 근사에서 무엇이 바뀌는지 예측한다.

## 화면과 조작

- 밝은 한국어 UI. 첫 화면에 질문 하나와 시작 버튼 하나.
- 데스크톱은 그림|조건 나란히, 모바일은 그림→조건→실행→결과 순서로 쌓인다.
- 보기는 정면·위·옆 2D와 3D(Three.js, 같은 상태를 그림). 3D에서는 정면·위·옆이
  카메라 위치가 된다. 자동 회전은 없다. WebGL이 안 되면 2D로 보여준다.
- 드래그는 숫자 입력·슬라이더·버튼·방향키로 대신한다.
- 중요한 다음 버튼 하나에만 반짝임. 동작 줄이기 설정에서는 굵은 테두리 + 한 단계 진행.
- 운영체제 고대비 모드에서도 버튼·테두리가 보인다. 200% 확대에서 가로 넘침이 없다.
- 업데이트 내역 버튼은 오른쪽 위에 항상 있다.
- 기록에는 개인 정보를 넣지 않는다. 저장 안 되면 현재 화면 + JSON 내보내기를 쓴다.

## P1 확장 (별도 모델, 기본 끄기)

- **약한 감쇠**: 점성 토크(−c·ω, c=0.0001 고정). 켜면 에너지가 조금씩 줄어서
  드리프트 0.5% 목표는 적용하지 않는다고 화면에 밝힌다.
- **지면 접촉 감지**: 바퀴를 축에 수직인 원반으로 보고 림 최저점이 지면에 닿으면
  그때 끝낸다(종료 이유 `groundContact`). 닿은 뒤 움직임은 계산하지 않는다.
  바퀴 반지름·지지점 높이는 가정값이라 화면에 밝힌다.
  예: 기울기 35°·20 rad/s·R=0.15 m·h=0.02 m이면 0.08초에 닿아 끝난다.
- P1을 끄면 P0와 결과가 같다는 검사가 있다 (`tests/p1.test.ts`).
- 실험 영상 비교는 출처를 검수할 수 없어서 넣지 않았다.

## 배포 메모 (아직 배포하지 않음)

- `vite.config.ts`의 `base`가 `"./"`라서 하위 경로에서도 자산이 깨지지 않는다.
- 배포할 때는 `npm run build` 뒤 `dist/`를 올리고, 공개 URL에서
  자산 경로·실행·비교·기록·업데이트 내역을 직접 확인한다 (공통 원칙 §6).
- 기록 형식: `schemaVersion, appId, createdAt, scenarioId, scenarioVersion,
  engineVersion, parameters, seed, observations, prediction, explanation`.
  시뮬레이션은 결정적이라 seed는 0 고정이다. 엔진 버전은 v0.2.0이다.
