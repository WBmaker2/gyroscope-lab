## 2026-09-24

- 예측을 고른 뒤 실험하도록 하고, 완료하면 비교 단계로 바로 이동할 수 있게 했다.
- 2배 비교는 정확한 값을 유지하며, 240 rad/s를 넘는 경우 값을 자르지 않고 안내한다.
- 세차·토크·각운동량을 먼저 설명하고 계산 세부정보는 접어서 볼 수 있게 했다.
- 실행 중 키보드 초점을 정지 버튼에 두고, 상태 안내 중복을 줄였다. 기록에는 예상·관찰·이유 문장 틀을 제공한다.
- 3D 불러오는 중과 완료 상태를 따로 알린다.

## 2026-09-23

- 팽이 연구소 P0 첫 화면을 만들었다. 예측→실험→비교→기록 흐름과 2D 투영·수치표를 제공한다.
- 계산 엔진(RK4, 시간 간격 1/2000초)과 화면을 분리했다. 빠른 회전 근사는 비교용으로만 표시한다.
- 실행 시간 10초, 축이 60도를 넘으면 종료된다. 지면 접촉은 계산하지 않는다.
- 작은 화면(320·360·768·1280px)에서도 가로 넘침 없이 쓸 수 있게 했다. 키보드와 동작 줄이기 설정을 지원한다.
- 시간 그래프(축 높이·에너지)를 추가했다. 그림 대신 수치표·그래프로 같은 상태를 볼 수 있다.
- 기록에 엔진 버전과 시나리오 버전을 함께 저장한다. 실행 없이 저장하는 실수를 막는다.
- 배포 전 점검을 마쳤다. 사용법은 README, 바뀐 점은 CHANGELOG에 적었다. 공개 주소 게시는 아직이다.
- 알려진 빚을 해소했다. main.ts를 작은 모듈 10개로 나눴다(전부 500줄 이하, 동작은 같음).
- 고대비 모드에 대응하고 200% 확대·읽기 순서를 확인했다. 과제 문장을 쉽게 고쳤다.
- 3D 보기를 붙였다. 같은 계산 결과를 입체로 보여주며, 안 되면 2D로 보여준다.
- P1 확장을 붙였다. 약한 감쇠와 지면 접촉 감지이며 기본은 꺼져 있다.
  닿은 뒤 움직임과 실험 영상 비교는 넣지 않았다.
- P1 입력 때문에 320px에서 가로 넘침이 다시 생겨 fieldset 최소 크기를 고쳤다.
  여섯 가지 너비에서 넘침이 없다.
- three.js를 처음부터 받지 않고 3D를 누를 때만 받게 했다. 첫 로딩은 50KB가 안 된다.
- 성능을 재서 기록했다. 한 단계 61.7ms로 100ms 목표 안에 든다.
- 물리 관점에서 교과 검토를 하고 문서로 남겼다. 수업 전 교사 확인이 필요하다.
- 깃허브에 공개하고 Pages로 열었다. 주소: https://wbmaker2.github.io/gyroscope-lab/
